## 两个入口

| 地址 | 实际用途 |
| --- | --- |
| `http://127.0.0.1:8080/` | 原有本机模拟站，五项手写小任务，不调用模型 |
| `http://127.0.0.1:8090/` | 通过 SSH 连接学校的18语言真实 Qwen3.5-9B 开发站 |

在 Windows 双击 `scripts/start_qwen_dev.cmd`，保持连接窗口开启，然后访问8090。
它只转发网站端口，不安装模型，不把模型端口直接开放到浏览器，也不会自动修改
服务器配置。若窗口报告连接失败或端口占用，应先解决该错误，不能把其他端口
上的页面当成已经连接到此开发站。

PowerShell 可执行 `& .\scripts\start_qwen_dev.ps1`。同学的 SSH 别名不叫 `75` 时，
可使用 `-SshHost` 指定自己的已批准别名，或直接执行：

```text
ssh -N -T -o ExitOnForwardFailure=yes -L 127.0.0.1:8090:127.0.0.1:8090 <自己的学校SSH别名>
```

两人均访问同一台学校服务器上的开发实例。关闭连接窗口后，本机8090不可访问；
服务器进程不会因此停止。当前模型/应用监督服务已启用，支持用户管理器启动时拉起；
未确认请求仍会阻止应用自动恢复，不能通过重启跳过核实。尚未重启整台主机做启动演练。

JSON、自定义防跨站请求头和预期用户校验。

## 服务实现与运维边界

当前实例已增加专用的备份、隔离恢复及诊断工具，使用
`operations/bin/qwen-development status|backup-request|verify-restore`。当前请求模式的
`backup-request`需先停止并排空应用，并提供受保护的备份配置，见
[请求模式备份与恢复](REQUEST_BACKUP_RESTORE.md)。旧`backup`仅用于旧串行模式。
2026-09-12已完成真实恢复及本机异机副本校验，见
[开发实例运维](QWEN_DEVELOPMENT_OPERATIONS.md)。旧实例的备份和健康检查脚本不用于8090。

入口为 `python -m linguistic_oj.qwen_development`，必须在 Linux 学校服务器上与
Qwen 服务同机运行。它：

- 要求18种语言均有已配置的通用词性任务，少一种即拒绝缩减启动。
- 验证全部公开描述、私有清单、数据文件哈希和现有模型运行证据。
- 不启动或替换 vLLM；使用已有 `127.0.0.1:8000/v1` Qwen9B 服务。
- 当前以一个共享执行器处理70个任务路由，最多32个在途样本请求、4份活跃作业；
  空闲槽位可借用，各任务不会各自再开一个模型实例。
- 模型请求无法确认结束时，持久请求账本阻断新工作，监督服务不会绕过75/78退出码
  反复重启。旧`uncertain-inference.json`也继续作为启动保护条件；操作员须按整组
  请求证据恢复，不能删除标记或账本解除阻断。
- 只监听 `127.0.0.1:8090`；所有任务仍为开发模式，不向外部学生开放。

首次启动显式使用 `--initialize`。程序仅创建独立的 `loj_dev18_` 前缀数据库，
核对其随机实例标记和所有者，绝不复用同名但未通过核对的数据库。后续启动省略
该开关，仅核对现有结构。更换评测合同会使实例指纹不匹配，需另行安排版本切换，
不能在有旧任务时直接覆盖。

服务器部署目录为：

```text

  state/         数据库归属、合同标记和进程锁
  logs/          私有启动日志及PID
  reports/       运维记录
```

数据只读复用既有 `candidate-20260903-v1-strict-upos-budget` 开发快照中的标准数据
和私有挑战清单；没有把私有清单加入源码打包。Python 与接口依赖使用已验证的
学校环境和独立依赖覆盖目录，不升级正在运行的模型环境。源码包是未提交工作树
快照，不是经过审查的正式 Git 发布。

900样本浏览器验收使用首次快照；当前快照保留相同的数据与评测合同，增加了故障
情况下的全局阻断保护，并已完成针对性测试和重启后的就绪检查。重启时确认没有
排队或运行任务，18条成功评测均保留；没有为了升级重复执行900个样本。

8090的页面来自学校服务器的代码快照。本机修改文件不会自动更新该页面；先在
8080做快速界面回归，再更新独立开发快照并验收。不要直接覆盖运行中的源码。

当前密码规则为8–128个字符，不强制混合字母、数字或符号，保留中文和已有密码的
兼容性。密码仍以 Argon2id 哈希保存。8位是本版本的易用性选择，不代表8位纯数字
属于强密码。密码规则更新后已在8090真实浏览器中验证7位拒绝、8位注册登录及
8位密码重置，全程未调用模型或改动已有账号密码。界面缓存旧提示时用 Ctrl+F5
