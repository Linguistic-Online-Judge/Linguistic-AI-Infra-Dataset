## 过程中的失败与修正

- v1在旧应用退出后的锁交接处被保护机制拦住，原模型未重启，原应用恢复；0次验收调用。
  改为有界等待并记录占用者，不强行解锁。
- v2模型和新应用已就绪，浏览器脚本错误读取客户端没有保留的统计字段，在注册和
  提交之前失败。已自动恢复原服务；0次验收调用。修正为检查实际任务目录字段。
- v3先在恢复后的站点完成无提交的页面/登录准备，再复用已确认清洁且绑定相同的
  请求账本，没有删除或重新初始化旧账本。真实验收成功。
- 本机报告上传遇到Windows默认编码问题，改为显式UTF-8后上传原成功报告；没有
  重新提交评测。正式端口的只读检查也保留独立隧道日志，未覆盖之前的日志。

三次尝试累计仍为250次真实验收调用，先前两次的回滚记录保留。不能抹去失败记录，
也不能把执行成功解释为全部模型输出正确。
