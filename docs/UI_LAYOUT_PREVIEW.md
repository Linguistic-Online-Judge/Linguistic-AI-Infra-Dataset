## 打开预览

浏览器打开：`http://127.0.0.1:8080/assets/layout-preview.html`。
本地服务关闭时，可先双击 `scripts/start_local_dev.cmd`。这不是8090真实评测站的改版。
也可以直接双击 `src/linguistic_oj/web/assets/layout-preview.html`，不需要启动任何服务。

原型使用独立的 `layout-preview.html/.css/.js`，不导入工作台的账号或评测代码。
所有内容是明确标记的预览示例，不执行模型、不读取账号、不写数据库。连接策略也
禁止后台请求。上方可切换任务目录、练习页、结果页；示例分数不代表真实模型成绩。

本轮落实：

- 独立目录，18语言均可筛选，不在首屏重复铺语言装饰带。
- 练习页只保留任务资料和编辑器；说明、示例、评分按标签组织。
- 编辑器只有一个主要操作，排行榜与开发工具不再占两侧。
- 结果页只强调分数、格式问题和继续修改，技术信息收起。
- 原型内可选择模板、编辑、查看结果布局并返回继续修改；草稿仅存本页内存，
  没有实现或声称已接入后端持久草稿。
- 用户已认可三页结构，并选择第1项Apple参考，明确不喜欢暗调。
- 当前已将灰阶结构稿更新为浅色高保真预览：白色面板、浅灰背景、深色正文，
  蓝色只用于主操作、链接与选中状态；用字号、留白和对齐建立层级。
- 练习页用逐词标签示例突出语言学任务，编辑器保持安静；结果页分别呈现分数
  和输出格式有效数，避免混淆。桌面双栏、手机单栏，保留键盘焦点提示。

### 文案检查

覆盖目录标签与空状态、五类任务说明/示例/评分、模板替换确认、结果折叠内容及预览提示。
用词按“准确、简洁、自然”检查；计分描述核对 `aggregation.py`、`evaluation.py`，
失败结果核对 `api.py`。主要修订如下：

| 程度 | 位置与原问题 | 修订 |
| --- | --- | --- |
| 主要 | “服务故障不会伪装成零分”使用拟人化表述，结果不明确 | “因服务异常而失败的评测不生成分数。” |
| 主要 | “输出格式不符的样本按规则计分”没有说明影响 | “输出格式不符合要求的样本仍计入评测，正确项数记为0。” |
| 主要 | 分词说明使用“而不是逐字符猜测”，未说明匹配单位 | 说明词的起止位置匹配，以及汇总词数计算F1的方法 |
| 主要 | 结果页对所有任务都提示返回相同词元数量，不适用于分词 | 统一提示对照任务输出示例检查格式要求 |
| 次要 | “这里放……”“默认不挤占……”等设计备注出现在页面 | 直接说明预览未包含的任务资料或指标 |

术语统一使用“提示词”“词元”“输出格式”；分数与格式有效数分开说明。
保留清楚的按钮动作、空状态清除筛选入口与替换草稿确认。

### 蓝色来源与应用

- 官方来源：[复旦大学色彩系统](https://www.fudan.edu.cn/2405/list.htm)。
- 已查看官方[标准色图](https://www.fudan.edu.cn/_upload/article/images/72/fa/4a0ce26f42aa9edc5174c3b9c347/fc66e114-83ba-4fc4-b4f1-8fc4d3f03dfd.png)，
  图中文字标注 `R14 G65 B156`，对应网页主色 **#0E419C**。
- 共享配色文件 `brand-palette.css`：主色 `#0e419c`、悬停色 `#0b347d`、
  浅色选中底 `#ecf0f7`、浅边线 `#c3d0e6`、行悬停底 `#f5f7fb`。
  后四种为本预览配套衍生色，不是官方另行规定的色值。
- 三页预览和方案页共同使用该配色，覆盖按钮、链接、标签、分数、选中和悬停状态。
  所有可选SVG同步使用该主色，折页以白色38%叠加得到浅色面。
- 方案页默认复旦蓝；墨黑用于查看图形的单色效果。背景仍保持浅色。

## 高级视觉参考

本轮核实了以下真实公开网站。学习其视觉方法，不等于复制代码、品牌或付费组件，
也不意味着这些网站的全部页面都适合语言学工作台。

| 参考 | 地址 | 可借鉴的视觉部分 | 转用于本平台时的取舍 |
| --- | --- | --- | --- |
| Apple | https://www.apple.com/macbook-pro/ | 清楚的字号比例、留白、分区节奏、精确的对齐 | 不把整屏产品图、长滚动动画搬进编辑工作台 |
| Untitled UI | https://www.untitledui.com/ | 输入框、按钮、表格、弹窗、状态组件的一致性 | 先看公开组件与页面示例，不需要购买套件或改用React |
| Stripe | https://stripe.com/ | 色彩组织、图文层次、复杂信息的分组 | 渐变和插画只作适量点缀，练习区保持安静 |
| Raycast | https://www.raycast.com/ | 暗色层次、控件质感、工具界面的精细交互 | 仅在用户确实偏好暗色时采用，不照搬大面积光效 |
| Pentagram | https://www.pentagram.com/ | 编辑式排版、字体气质、文化与教育项目案例 | 用于品牌和标题气质，不把作品集布局当后台模板 |
| Instrument | https://www.instrument.com/ | 大小比例、节奏、品牌与数字产品的整体表达 | 用于寻找整体气质，不引入与任务无关的展示动画 |
